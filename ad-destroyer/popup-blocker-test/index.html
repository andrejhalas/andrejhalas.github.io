What the popup-blocker test measures

The direct test calls window.open() during your click. The delayed test waits six seconds after your click before attempting the same call. Browsers often permit a window opened directly by a user action; a delay may cause that permission to expire. The exact rules vary.

When a usable window handle is returned and remains open, the test reports allowed. A missing or immediately closed handle is reported as likely blocked or unavailable. An exception produces an inconclusive result. A browser extension or embedded webview can affect all three outcomes.

Why an “allowed” result is not a failure

A popup blocker can work correctly and still allow a window you deliberately requested. An allowed direct test does not prove that unsolicited popups can open. Even an allowed delayed test is only evidence about this one attempt, under the settings and exceptions active on this site.

Limits: popups, ads, and notifications are different

  • This tests a new window or tab, not an overlay drawn inside an existing page. Popup blockers generally do not remove ordinary HTML overlays.
  • It does not test content filtering, advertising trackers, malicious downloads, or website notifications.
  • A null window handle is not definitive proof of blocking. Browser isolation rules, extensions, and webviews may also make the result unavailable.
  • Your browser may open the test as a tab instead of a small window. The window may open behind the current page.
  • Per-site permissions and managed-device policies can override default behavior.

Browser-specific troubleshooting

Chrome and Edge

Review the site’s permissions and the “Pop-ups and redirects” setting. Check whether this site has an exception. Notifications use a separate permission. On Edge, search Settings for “pop-ups” if the settings navigation differs.

Official Chrome popup settings · Official Microsoft Edge popup guidance

Firefox

Check the popup-blocking setting under Privacy & Security and review site exceptions. Firefox may still allow popups triggered by intentional clicks.

Official Firefox settings and exceptions

Safari on iPhone, iPad, and Mac

On iPhone and iPad, look for Block Pop-ups in Safari settings. On Mac, review Safari’s Websites settings for popup windows. Device version and site-specific choices can change the controls shown.

Official Safari popup guidance

In-app browsers

If this test cannot determine a result, open the page in your normal browser. In-app webviews may suppress new windows or return incomplete information.
