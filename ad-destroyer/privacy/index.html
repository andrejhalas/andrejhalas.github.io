Privacy & analytics.

No accounts. No personal data forms. No advertising network.

What this MVP does

The game, simulation, and educational examples run in your browser. Scores and demo choices are held in memory for the current page session. They are not saved to a database or sent to an analytics endpoint by the game. The site does not set analytics cookies or request access to your camera, microphone, or location.

Local interaction events

The application emits named events inside the browser, such as game_start and popup_test_completed. These contain only limited game data such as weapon, score, boss type, test mode, and outcome. In the default build, there is no collector and these events are not transmitted.

Optional Cloudflare Web Analytics

The owner can enable Cloudflare’s Web Analytics beacon using a public configuration token. If enabled, the beacon sends site visit and performance information to Cloudflare. It is separate from the local game events and does not collect those events through this implementation. This MVP leaves the token empty by default.

GitHub Pages can process request information to host and secure this website. Hosting logs are different from game analytics. Review GitHub’s privacy statement. If optional Cloudflare analytics is enabled, Cloudflare’s privacy policy also applies.

Sharing and external links

Sharing uses your device’s share interface or copies score text to your clipboard after you choose Share. If those features are unavailable, you can copy the text manually. External help links take you to the linked provider’s website and its own privacy practices.

Future changes

Real advertising, additional analytics collection, and persistent accounts are outside this MVP. Before enabling a new collector, the owner should update this notice and assess applicable consent and disclosure requirements for the actual configuration and audience.
